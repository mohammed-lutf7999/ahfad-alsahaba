## 📖 نبذة عن اللعبة (About the Game)

**معركة أحفاد الصحابة** هي لعبة مسابقات تعليمية وثقافية إسلامية تفاعلية تجمع بين إثارة التحدي وعمق المعرفة الشرعية والتاريخية. تهدف إلى تعزيز الثقافة الإسلامية لدى الشباب والناشئة بأسلوب ممتع وشيق يجمع بين اللعب الفردي والجماعي.

---

## ✨ المميزات الرئيسية (Key Features)

* **🕌 أقسام معرفية متنوعة**:
  * القرآن الكريم وعلومه
  * الحديث الشريف والسنة النبوية
  * السيرة النبوية العطرة
  * قصص وسير الصحابة والتابعين
  * الفقه والعبادات
  * العقيدة والتاريخ الإسلامي
* **⚔️ أنماط اللعب المتعددة**:
  * **التحدي الفردي المستمر**: مستويات متدرجة الصعوبة ونقاط ذكاء.
  * **المواجهة المباشرة (Multiplayer Realtime)**: تنافس حي عبر شبكة Supabase السحابية.
  * **تحدي البوت الذكي**: ذكاء اصطناعي للمواجهة عند عدم توفر خصم بشري.
  * **اللعب الجماعي المحلي (Nearby & Bluetooth)**: تنافس مباشر بدون إنترنت عبر التقارب المكاني.
* **👑 إمبراطورية المعرفة (Empire Mode)**: بناء وتطوير مدن وممالك إسلامية بناءً على المعرفة الدينية والنقاط.
* **🔊 تجربة صوتية وبصرية متكاملة**:
  * مؤثرات صوتية تشويقية للمؤقت والتفاعل.
  * خط عربي أصيل مدمج (Cairo).
  * أيقونات متكيفة (Adaptive Icons) لجميع شاشات الأندرويد.
* **🛡️ متوافق مع معايير Google Play 2024-2026**:
  * دعم Android 15 (Target SDK 35).
  * خيار حذف الحساب والبيانات السحابية بالكامل لحماية الخصوصية.

## 🛠️ البنية التقنية (Tech Stack)

* **إطار العمل (Framework)**: Flutter SDK 3.32.8 / Dart SDK 3.8.1
* **قاعدة البيانات والسحابة (Backend)**: Supabase (PostgreSQL, Realtime WebSockets, Edge Functions)
* **المصادقة (Auth)**: Google Sign-In & Supabase Auth
* **التخزين المحلي (Local Storage)**: SharedPreferences & Local JSON Datasets
* **الصوتيات والوسائط (Media)**: AudioPlayers & Flutter Local Notifications

## 🚀 التشغيل والتطوير (Getting Started)

1. **استنساخ المستودع (Clone repository)**:
   ```bash
   git clone https://github.com/mohammed-lutf7999/ahfad-alsahaba.git
   cd ahfad-alsahaba
   ```

2. **تثبيت الحزم (Install dependencies)**:
   ```bash
   flutter pub get
   ```

3. **تشغيل الاختبارات (Run tests)**:
   ```bash
   flutter test
   ```

4. **بناء حزمة الإنتاج للمتجر (Build Release Bundle)**:
   ```bash
   flutter build appbundle --release
   ```
