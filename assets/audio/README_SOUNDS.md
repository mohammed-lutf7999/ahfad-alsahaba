# Sound Effects

The application expects the following sound files in this directory (`assets/audio/`):

1.  **correct.mp3**: Played when the user selects the correct answer. (Suggest: A soft bell or chime)
2.  **wrong.mp3**: Played when the user selects a wrong answer. (Suggest: A soft glass break or subtle thud)
3.  **level_complete.mp3**: Played when a level is completed successfully. (Suggest: A small fanfare or success tune)
4.  **click.mp3**: Played when buttons are clicked. (Suggest: A soft wooden or mechanical click)

## Where to get free sounds?

You can find high-quality free sound effects at:
- [FreeSound.org](https://freesound.org/)
- [OpenGameArt.org](https://opengameart.org/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

Ensure you respect the licenses (CC0 is best).
