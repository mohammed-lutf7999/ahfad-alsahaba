# Fonts

The application is configured to use the following Arabic fonts to ensure a premium look:

1.  **Amiri**: Used for titles and Quranic text feel.
    *   `Amiri-Regular.ttf`
    *   `Amiri-Bold.ttf`
    *   [Download from Google Fonts](https://fonts.google.com/specimen/Amiri)

2.  **Cairo**: Used for body text and UI elements for readability.
    *   `Cairo-Regular.ttf`
    *   `Cairo-Bold.ttf`
    *   [Download from Google Fonts](https://fonts.google.com/specimen/Cairo)

**Action Required:**
Please download these fonts (TTF format) and place them in this directory (`assets/fonts/`). Ensure the filenames match exactly as listed above.
