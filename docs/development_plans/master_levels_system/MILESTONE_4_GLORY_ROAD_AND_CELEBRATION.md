# 🏆 وثيقة المرحلة الرابعة: شاشة طريق المجد والاحتفاليات الملحمية
## Milestone 4 (M4) — Glory Road Screen & Epic Level-Up Celebrations

> **المسار:** `docs/development_plans/master_levels_system/MILESTONE_4_GLORY_ROAD_AND_CELEBRATION.md`  
> **الهدف:** بناء شاشة "طريق المجد" التفاعلية لاستعراض مسار الـ 50 مستوى، ونافذة الاحتفالية الملحمية بالترقية مع دمج النبض اللمسي والأصوات البشرية الخالصة.

---

## 1. الأهداف التفصيلية ونطاق العمل (Scope & Objectives)

1. **بناء شاشة "طريق المجد" (`GloryRoadScreen`):**
   * مسار تفاعلي شاقولي (Vertical Stepper / Journey Road) يستعرض المستويات من 1 إلى 50:
     - **المستويات المنجزة:** تظهر بعلامة الفتح الذهبية وشارة اللقب.
     - **المستوى الحالي:** يظهر متوهجاً ومحاطاً بهالة خضراء مع موضع شريط التقدم الفعلي.
     - **المستويات القادمة:** تظهر بقفل أنيق مع معاينة للقب والمكافأة القادمة (تحفيز دائم).
   * تبويب علوي يتيح التبديل بين:
     * مسار مستويات المعرفة (XP Road).
     * مسار ميادين الشرف والكؤوس (Arenas Road).
2. **بناء نافذة الاحتفالية الكبرى بالترقية (`LevelUpCelebrationDialog`):**
   * عند إجابة اللاعب على سؤال أو انتهاء مباراة توصله لمستوى جديد:
     - تتوقف الواجهة وتظهر شاشة احتفالية ذات خلفية نصف شفافة داكنة.
     - **انفجار جزيئات ذهبية ونورانية أندلسية (Particle System).**
     - **تشغيل التكبير والهمهمة البشرية المهيبة فوراً بدون أي آلات موسيقية.**
     - **إطلاق اهتزاز لمسي مزدوج وثقيل (Heavy Impact Haptic).**
     - عرض اللقب الجديد بخط عربي مهيب مع زري: «متابعة المسيرة» و«مشاركة الفخر 📲».
3. **بناء نافذة الانتقال لميدان جديد (`ArenaPromotionDialog`):**
   * عند تجاوز حد الكؤوس لميدان جديد (مثلاً الانتقال إلى ميدان اليرموك عند 1200 كأس):
     - تظهر رسالة فخر: *"مبارك أيها الفارس! لقد دخلت ميدان اليرموك التنافسي!"*.

## 3. التكامل الحسي والصوتي (Sensory Wiring)

```dart
// دالة إطلاق الاحتفالية
Future<void> triggerLevelUpCelebration(BuildContext context, PlayerLevel newLevel) async {
  // 1. تشغيل النبض اللمسي المتتابع
  HapticFeedback.heavyImpact();
  await Future.delayed(const Duration(milliseconds: 150));
  HapticFeedback.heavyImpact();

  // 2. تشغيل الصوت البشري الوقور
  SoundService().playRankUp();

  // 3. فتح نافذة الاحتفالية
  if (context.mounted) {
    await showDialog(
      context: context,
      barrierDismissible: false,
      builder: (_) => LevelUpCelebrationDialog(level: newLevel),
    );
  }
}
```
