## 🏛️ 1. الأهداف المعمارية والوظيفية (Architectural & Functional Goals)

1. **توسعة محرك التكرار المتباعد («المعلم الحكيم» - Advanced SM-2 Spaced Repetition):**
   - تطوير المنظومة التأسيسية الموجودة في `SpacedRepetitionService` لتعتمد خوارزمية جدولة زمنية تصاعدية (24 ساعة $\rightarrow$ 3 أيام $\rightarrow$ 7 أيام $\rightarrow$ 14 يوماً $\rightarrow$ إتقان دائم).
   - احتساب مؤشر "الإتقان المعرفي" (Mastery Index) لكل قسم من أقسام السيرة والتاريخ.

2. **شاشة «خزانة السيرة والمراجعة الشخصية» (Lore Vault & Personal Review Hub):**
   - واجهة مخصصة ووقورة يمكن للاعب الدخول إليها من الشاشة الرئيسية.
   - تعرض بطاقات الأسئلة التي تعثر فيها اللاعب مع إضاءاتها التاريخية الموثقة.
   - إمكانية فرز الأسئلة حسب القسم، أو حسب تاريخ الاستحقاق.

3. **طور «تحدي تدارك الأخطاء» (Mistake Mastery Challenge Mode):**
   - طور لعب سريع يولد جولة مكونة من 5 أو 10 أسئلة مستقاة حصرياً من سلة أخطاء اللاعب المستحقة للمراجعة.
   - عند الإجابة الصحيحة على السؤال مرتين متتاليتين، يتم إخراجه من سلة الأخطاء واعتباره "متقناً تماماً"، مع منح اللاعب نقاط مكافأة استدراكية.

4. **تكامل التخزين المحلي والمزامنة السحابية (Offline-First with Cloud Backup):**
   - تخزين سجل الأخطاء والتواريخ في `SharedPrefsService` محلياً للعمل دون إنترنت.
   - مزامنة سحابية غير معطلة مع جدول `user_progress` في Supabase عند تسجيل الدخول بحساب Google.

## 🗄️ 3. منطق خوارزمية التكرار المتباعد (`SpacedRepetitionService`)

```dart
/// حساب تاريخ المراجعة القادم بناءً على مستوى الإتقان
DateTime calculateNextReviewDate(int masteryLevel) {
  final now = DateTime.now();
  switch (masteryLevel) {
    case 1:
      return now.add(const Duration(hours: 24));
    case 2:
      return now.add(const Duration(days: 3));
    case 3:
      return now.add(const Duration(days: 7));
    case 4:
      return now.add(const Duration(days: 14));
    default:
      // إتقان تام: مراجعة تذكيرية كل 30 يوماً
      return now.add(const Duration(days: 30));
  }
}
```

## ✅ 4. معايير القبول والتحقق (Definition of Done)

1. **العمل التام أوفلاين:** إمكانية فتح خزانة السيرة ولعب طور تدارك الأخطاء بدون اتصال بالإنترنت.
2. **دقة الجدولة الزمنية:** استدعاء الأسئلة المستحقة فقط في تاريخها بدقة متناهية ودون تكرار مزعج.
3. **وضوح الشروحات التاريخية:** التحقق من صحة جميع الإضاءات التاريخية المعروضة في بطاقات المراجعة ومطابقتها للمراجع السنية المعتمدة.
4. **تجاوب الواجهة:** تصميم متجاوب بدون أي أخطاء `RenderFlex overflow` على كافة الأجهزة والشاشات الصغيرة ($360\text{dp}$).
5. **تغطية الاختبارات:** اختبارات وحدة واختبارات واجهة بنسبة $100\%$ لخدمة الجدولة والشاشات التابعة لها.
