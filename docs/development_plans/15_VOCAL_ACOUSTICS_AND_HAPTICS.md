## 🏛️ 1. الأهداف المعمارية والوظيفية (Architectural & Functional Goals)

1. **الهندسة الصوتية البشرية والبيئية (Pure Vocal Harmonies & Natural Acoustics):**
   - استبعاد أي مؤثرات إلكترونية أو موسيقية، والاعتماد حصرياً على أصوات بشرية عربية فصيحة وأصوات بيئية طبيعية:
     * **حفيف ورق البردي ومخطوطات السيرة:** عند تقليب الأسئلة، فتح كتب المكتبة، أو تصفح خريطة الفتوحات.
     * **وقع الخيل وصليل السيوف البعيد:** في شاشات المبارزة (`VersusScreen`) وبدء جولات التحدي.
     * **الهتافات البشرية الوقورة والتكبير:**
       - عند الفوز الساحق: *"الله أكبر ولله الحمد!"*.
       - عند إحراز سلسلة إجابات صائبة (Combo Streak): *"نصرٌ من الله وفتحٌ قريب"*.
       - عند التفوق في التحدي الفردي: *"أفلح وجهك يا بطل!"*.
       - عند إتمام المستوى بـ 3 نجوم: همهمة بشرية ناعمة مع صدى مهيب.
   - ضغط الصوتيات بتقنيات Ogg Vorbis الحديثة بمعدل $64\text{kbps}$ إلى $96\text{kbps}$ لضمان ألا يتجاوز الحجم الإجمالي المضاف لحزمة التطبيق **$1.5\text{ MB}$ فقط**.

2. **محرك النبض اللمسي التكتيكي (Tactical Dual-Pulse Haptic Engine):**
   - دمج محرك اهتزاز الهاتف مع ديناميكية المواجهات لإشعال الحماس التنافسي:
     * **نبض دقات القلب المتسارعة:** في آخر 3 ثوانٍ من عداد السؤال لتنبيه اللاعب حركياً.
     * **النبض المزدوج الثقيل (`HeavyImpact`):** عند مضاعفة النقاط أو تحقيق إجابة صائبة في الثانية الأخيرة.
     * **النقرة الناعمة الخفيفة (`SelectionClick`):** عند لمس الخيارات والأزرار لتقديم استجابة لمسية فورية.
     * **حفظ الطاقة التام:** إيقاف النبض فوراً عند تفعيل وضع توفير الطاقة أو عند تعطيله من شاشة الإعدادات.

3. **إدارة مشغلات الصوت بالذاكرة (Sound Pool & Low Latency):**
   - استخدام مصفوفة مشغلات مسبقة التجهيز (`AudioPlayer Pool`) لتشغيل المؤثر في زمن قياسي ($< 15\text{ms}$) دون أي تأخير أو استهلاك مفرط للذاكرة العشوائية.

## 💻 3. المنطق البرمجي للنبض اللمسي (`HapticService`):

```dart
import 'package:flutter/services.dart';

class HapticService {
  static final HapticService instance = HapticService._();
  HapticService._();

  bool isHapticsEnabled = true;

  void lightTap() {
    if (!isHapticsEnabled) return;
    HapticFeedback.selectionClick();
  }

  void mediumImpact() {
    if (!isHapticsEnabled) return;
    HapticFeedback.mediumImpact();
  }

  void victoryDoublePulse() async {
    if (!isHapticsEnabled) return;
    HapticFeedback.heavyImpact();
    await Future.delayed(const Duration(milliseconds: 120));
    HapticFeedback.heavyImpact();
  }

  void heartbeatTick() {
    if (!isHapticsEnabled) return;
    HapticFeedback.lightImpact();
  }
}
```

## ✅ 4. معايير القبول والتحقق (Definition of Done)

1. **الخلو التام من المعازف:** مراجعة واعتماد جميع الملفات الصوتية للتأكد من خلوها من أي آلات موسيقية أو إيقاعات محرمة.
2. **سرعة الاستجابة الصوتية:** تشغيل المؤثر الصوتي في أقل من $20\text{ms}$ من لحظة النقر دون أي تأخير مسموع.
3. **خفة الحجم:** عدم زيادة حجم حزمة الـ APK أو AAB بأكثر من $1.5\text{ MB}$.
4. **التحكم الكامل للمستخدم:** توفير خيارات مستقلة تماماً في الإعدادات لكتم المؤثرات الصوتية، أو تعطيل الهتافات، أو إيقاف النبض اللمسي.
5. **تغطية الاختبارات:** اختبارات وحدة لـ `HapticService` و `SoundService` تضمن عدم انهيار التطبيق على الأجهزة التي لا تدعم الهزاز المتقدم.
