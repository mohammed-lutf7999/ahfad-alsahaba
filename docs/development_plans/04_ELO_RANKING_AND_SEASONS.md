---

## 1. الأهداف المعمارية والوظيفية

1. **نظام رتب الفرسان (Rank Tiers / ELO System):**
   - تحويل نقاط الكؤوس (`Trophies`) المكتسبة من التحديات الجماعية إلى سلم رتب تاريخي ذي هيبة:
     * **الرتبة 1: «مبارز مبتدئ»** (0 - 299 كأساً) — شارة نحاسية.
     * **الرتبة 2: «فارس الميدان»** (300 - 699 كأساً) — شارة فضية مع سيفين متقاطعين.
     * **الرتبة 3: «قائد الكتيبة»** (700 - 1199 كأساً) — شارة ذهبية براقة.
     * **الرتبة 4: «حكيم السيرة»** (1200 - 1999 كأساً) — شارة ياقوتية ملكية.
     * **الرتبة 5 الأسطورية: «نخبة الأحفاد»** (2000+ كأس) — شارة ماسية مع إطار متوهج دائم في كل الشاشات.
2. **شاشة المتصدرين العالمية المحدثة ([`global_ranking_screen.dart`](file:///d:/newcuzeapp/flutter_application_1/lib/ui/screens/global_ranking_screen.dart)):**
   - إضافة تبويبين مستقلين:
     * **تبويب «فرسان الكؤوس 🏆»:** ترتيب المتنافسين في التحديات العالمية اللحظية مع إظهار رتبهم.
     * **تبويب «علماء المعرفة 🌟»:** ترتيب المتصدرين في النقاط الكلية للمسابقات الفردية.
3. **مواسم السيرة (Monthly Battle Pass):**
   - إطلاق موسم جديد كل أول شهر هجري/ميلادي (مثلاً: *موسم أبطال اليرموك* أو *موسم العشرة المبشرين*).
   - مسار مكافآت مكوّن من 30 درجة يمنح اللاعب عند كل ترقية: ثيمات حصرية، ألقاب، أو بطاقات إنجازات نادرة.

---

## 2. البنية السحابية في Supabase

```sql
-- إضافة حقول الرتبة والكؤوس لجدول المتصدرين
ALTER TABLE public.leaderboard
ADD COLUMN IF NOT EXISTS trophies INT DEFAULT 0,
ADD COLUMN IF NOT EXISTS rank_tier TEXT DEFAULT 'مبارز مبتدئ',
ADD COLUMN IF NOT EXISTS current_season INT DEFAULT 1;

-- إنشاء فهرس سريع لترتيب الكؤوس
CREATE INDEX IF NOT EXISTS idx_leaderboard_trophies ON public.leaderboard (trophies DESC);
```
